# i18n Translation Guide

This project uses `i18next` and `react-i18next` for internationalization.

## Translation Files

Translation files are located in `src/i18n/locales/`:
- `en.json`: English (Source)
- `ar.json`: Arabic

## How to use translations

### 1. Simple Translation Hook
Use the `useTranslation` hook in your components:

```tsx
import { useTranslation } from 'react-i18next'

export function MyComponent() {
  const { t } = useTranslation()
  
  return (
    <div>
      <h1>{t('dashboard.title')}</h1>
      <p>{t('common.search')}</p>
    </div>
  )
}
```

### 2. Trans Component (for complex HTML)
If you need to include HTML or components within a translation:

```tsx
import { Trans } from 'react-i18next'

<Trans i18nKey="myKey">
  Welcome to <strong>Bluetide</strong>
</Trans>
```

## Developer Workflow

1.  **Write code in English first**: You can use hardcoded strings temporarily.
2.  **Move strings to `en.json`**: Choose a logical key structure (e.g., `feature.item`).
3.  **Add Arabic equivalent in `ar.json`**: If you don't know the translation, you can use the English string temporarily or ask for help.
4.  **Replace hardcoded strings with `t('key')`**.

## RTL Support
The `LanguageProvider` automatically handles the `dir="rtl"` attribute and adds a `.font-arabic` class to the `html` tag when Arabic is active. Ensure your CSS uses logical properties (e.g., `margin-inline-start` instead of `margin-left`) where possible, or rely on Tailwind's RTL support.
